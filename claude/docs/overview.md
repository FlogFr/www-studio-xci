# Overview

## What the site is

studio-xci.fr is Florian Grignon's library, directory and documentation of all
his projects — web or not. It is a catch-all on purpose, so the structure has to
make it easy to know where you are: the site is split into five **universes**,
each with its own visual identity.

| # | Universe | Slug | Content | Main audience |
|---|----------|------|---------|---------------|
| I | Son | `/son/` | MereDSP206 app, the sound system, the constant-directivity horn project | Public / DJs / DSP 206 owners — MereDSP206 is promoted |
| II | Logiciel | `/logiciel/` | Free software, Linux, infrastructure, *The Art Of Kubernetes* book, Infratelier | Tech peers, recruiters, training clients |
| III | Motion | `/motion/` | Blender, 2D/3D animation, renders | Portfolio |
| IV | Web | `/web/` | Websites made for friends, associations and own projects | Professional references (LinkedIn) |
| V | Others | `/others/` | Shaping (foils, boards, composites — hydrocamp.fr) and anything else | Curious visitors, makers |

## The name

**XCI** is 91 in Roman numerals (XC = 90, I = 1): Florian's year of birth. The
Roman numerals are reused to number the universes (I → V), and 404 is "CDIV".

## Goals

1. Promote MereDSP206 so DSP 206 owners find it (Google, "t.racks DSP 206 Linux /
   Android").
2. Give professional references (web sites, book, infra) a link-able home.
3. Document personal projects (sound system, horn, shaping) for the community.
4. Be pleasant to browse and well ranked: fast static pages, clean semantics,
   structured data.
